# YouTube Song Provider

A planned, self-hosted YouTube song provider compatible with Karaoke Eternal's [SongProvider v0](https://github.com/bhj/reference-provider-song) HTTP API.

This repository currently contains project documentation only. The service is not implemented yet.

The first release is planned to provide a configurable karaoke profile, channel-specific artist and title extraction, download quality preferences, an administration interface, and Docker support for ARM64. See [CHANGELOG.md](CHANGELOG.md) for project changes.
